VN Revival — The Forest of Love: Windows language installer

1. Extract the ENTIRE ZIP to a folder. Keep Resources next to the EXE.
2. Close the game. Open Forest Language Installer.exe.
3. Select your language and click Install language. If asked, choose the folder
   containing The Forest of Love.exe. The original Windows game version 0.45
   is required; other builds and unknown manual patches are safely rejected.
4. When installation finishes, click Launch game.

Run this app again to change language. Choose English (original) to restore
the original files. The selection stays in effect after restarting the game.
All included language packs work offline. No API key or developer tools needed.

Keep the game's .vnrevival-forest folder: it holds verified original backups,
the complete language package and recovery state. Never delete it to switch
languages. An interrupted install is reconciled on the next installation attempt.
Saves, player settings, app.info and unrelated mods are preserved.

This package contains finished wording/resource builds. Most languages still
need complete in-game font/layout testing. Hindi, Swahili and Ukrainian are
omitted while their final independent review remains unresolved. Russian uses
the owner's accepted baseline, rather than the later unaccepted wording revision.

Windows 10/11 x64, built-in Windows PowerShell 5.1 and .NET Framework 4.8.
This is a resource patch, not a copy of the game. Keep your original game.
