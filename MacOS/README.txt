VN Revival — The Forest of Love: macOS language launcher

1. Extract the ZIP. Move Forest Languages.app to Applications if desired.
2. Close The Forest of Love. Open Forest Languages.app.
3. Choose your language and click Apply language. If necessary, click Choose
   game and select the original TheForestOfLove.app (native macOS version 0.45).
4. When preparation finishes, click Launch game in this launcher.
   The launcher directly runs the managed copy's Contents/MacOS executable;
   no Terminal command is needed. Startup output is saved in the launcher's Logs.

Run this launcher again to change language. English (original) restores English
in the managed copy. All 27 included language packs are available offline.
No API key, Python, .NET, developer tools or subscription is required.

The original installed game is never patched. A separate localized copy is
stored in ~/Library/Application Support/VN Revival/Forest/Current. Always launch
this copy through the launcher to use its selected language. The game's bundle
identifier and save location stay the same. Contents/tfol.settings is preserved
when switching languages; external saves are never edited by this app.
Keep the original game installed. At least 4 GB of free disk space is required.
Unknown modifications of the 14 owned resource paths are rejected; unrelated
files and mods are preserved. An interrupted install recovers on the next Apply.

macOS 14 or later, Apple Silicon and Intel. The app and localized game copy are
ad-hoc signed, not Apple-notarized. If macOS asks, use its Open Anyway option
in Privacy & Security for this app. The launcher never disables Gatekeeper.

These are compiled wording/resource builds. Full in-game font/layout acceptance
is still pending for most languages. Hindi, Swahili and Ukrainian are excluded
because final independent review is unresolved. Russian uses the owner-accepted
baseline. This launcher does not include or replace the original game.
