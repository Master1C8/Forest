# Embedded CJK font provenance

The single-file Korean and Taiwan Traditional Chinese language documents contain
hash-addressed Noto CJK font data. Keep the accompanying SIL Open Font License
with any future authorized redistribution. Canonical candidate provenance is in
localization/fonts/noto-cjk/provenance.json. Korean authored provenance is retained
in localization/editorial-delivery/six-new-locales-20261101-01/ko/review-ready-v1/licenses/.
The language fontAssets keys bind embedded font bytes; compiler manifests bind the
actual generated resources. Static compilation is separate from native rendering.
No installer, release or publication is created by this documentation.
