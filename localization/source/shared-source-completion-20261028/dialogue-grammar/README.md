# Complete frozen dialogue lexical protection

This source supplement inventories every one of the frozen 12,246 logical fields
and 24,492 physical occurrences. It changes no frozen source, language helper,
proposal, target, texture, or installation. Source-field eligibility, runtime
selection, special-scene discovery, and semantic acceptance remain separate.

The exact source-bound lexer is reused read-only from the existing Russian lane;
its hash is pinned alongside the reviewed consumer evidence. It finds 6,174
square controls and 919 angle-markup spans. Every angle span stays exact, including
unconfigured effects and source anomalies; this is not proof of effect registration.
No brace placeholders or RPG Maker escape tokens occur in this exact corpus.
There are also 290 LF and one CR outside protected operands; no pipe separators
occur. Their individual source positions and values are recorded separately.

All six lexical exceptions were read and explicitly decided in
`span-decisions.json`. Two separate flower narrations contain literal bracketed
prose. Two detached SHOW TUTORIAL SPLASH? questions are also literal bracket
content at the FormattedText parser boundary; their prior whole-field preservation
proposals remain unchanged. This lexical decision grants no translation eligibility
or reachability. The formatter replaces only its named control families, and the
reviewed UI/typewriter methods retain the other square brackets. Each of these
four fields therefore has two exact delimiter spans and separately identifiable
literal content. Two other fields contain an extra closing bracket after a
portrait control; those original anomalies remain exact. The resulting inventory
has 7,103 markup/delimiter spans and zero unclassified lexical spans.

`protected-spans.jsonl` preserves original ordered IDs, complete source hashes,
pointers, all physical occurrences, codepoint and UTF-8 bounds, exact span values,
and line separators. Codepoint bounds are not C# UTF-16 indices. Complete source
partition/reconstruction is checked for every field; equal wording never merges
IDs. `exceptions.json` records the six source fields' exception spans.

The coordinator read complete saved `FormattedText.cs`, `UITools.GetUIFormattedText`,
`UITextField.set_text`, legacy typewriter `Tokenize`, and the supplied TMP
StartTyping/PlayText/ProcessRPGMakerCodes/PeelRPGMakerTokenFromFront bodies for this
named grammar predicate. These are saved consumer artifacts, not new game
execution. Their pinned provenance must be reconciled by the owning common-source
gate. No arbitrary framework recursion or claim about an unread callee is made.
