## Original helper semantics

`source-trace.json` gives exact IL locators. Extraction is not a paired-span parser.
Its guarded regex concatenates `\[\/?em[1-`, setting count and `]\]`, a character
class rather than an arbitrary integer range. The evaluator parses the penultimate
character as an index, removes each matched token, and for a valid index clears all
previous emphasis records and adds one `(0, Int32.MaxValue, color, bold, italic,
underline)` record. Opening/closing distinction and match positions are ignored;
the last valid marker, including a closing marker, controls that whole-text record.
Actual rendering of its length is not established. Zero/multidigit setting-count
regex behavior is outside the single-digit synthetic adapter.

Rich-text replacement loops indices ascending. Only an index with its opening token
present gets global opening/closing replacements. It emits optional bold, optional
italic, then color; closes color, italic, bold. Underline is not emitted. Closing-only
indices stay unchanged. It validates neither pairing nor nesting and returns no
emphasis records. Tag-only input can become empty in extraction but nonempty markup
in rich mode. This distinction is synthetic coverage, not a scoped-source defect:
none of the bounded originals takes the guarded path.

The constructor normalizes null text to empty and null emphases to its static
noEmphases field, then assigns every property directly. All scoped outputs supply
nonnull empty emphasis arrays. It does not trim or strip other tags. Original
ToWebColor uses RGBA times255, integer conversion and lowercase hex; synthetic
controls supply formatted colors rather than claiming Python reproduces Unity floats.
