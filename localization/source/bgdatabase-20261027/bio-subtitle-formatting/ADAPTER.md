## Original grammar

`source-trace.json` pins exact method/IL locators. The unchanged metadata inspector
supplies17 successful selections and22 method bodies, including actual nested method
lists before selecting evaluator names. There were no failed new metadata selections;
previous failed selection accounting remains byte-identical in the prior supplement.

Parse runs Lua replacement, prompt extraction, variable replacement, autocase, pipes,
pictures, flags, position and panel before the still-unaccepted emphasis branch.
The four reverse-scan helpers have a100-iteration bound. This is not an exhaustive
recursive evaluator. Lua and prompt regexes use greedy dot within a line; ordinary
variable/autocase regexes stop at the next closing bracket. Prompt extraction returns
the last assigned key while removing its match, so separate normal prompt tags are
processed right-to-left and the leftmost key survives. A later bracket on the same
line can be absorbed into the prompt key. Remaining text is not trimmed.

Lua evaluates trimmed code, adding `return ` when absent; variables/autocase use
DialogueLua.GetVariable. Their evaluators return empty on caught failure. Values,
execution success, side effects and runtime culture are unknown. Injected values can
introduce syntax for later stages; earlier stages are not automatically rerun.
Autocase skips only ASCII space/LF before examining the prefix. The original
FirstLetterToLower one-character branch calls ToUpper; preserve this finding rather
than modifying original code or silently normalizing its behavior.

Every pipe becomes LF. Exact flags use Contains plus global String.Replace without
trimming, case folding or whitespace normalization. noSubtitle and empty text are
independent properties. Pictures use the original `[0-9a-zA-z_]` range, not a corrected
alphabet. Numeric Int32 parsing precedes variable lookup; every matched tag is removed
and the last assigned index wins. Position/panel methods and their evaluators are also
pinned, but no such inputs occur in the bounded records.
