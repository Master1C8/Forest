# Shared localization dependency scheduling repair

The owner clarified that the coordinator must repair the shared process, not author translations. This change preserves existing linguistic and technical workers and their immutable execution versions.

Failure: a language lane can publish a precise technical request and stop with a finite consumption task, but the supervisor returns permanently. Historical source-only wakeups cannot observe a completed locale resource delivery. Repeated owner resumes merely repair individual symptoms.

The shared fix uses an exact request → saved resource delivery → distinct clean review → immutable ready receipt → one existing-language-task continuation. All six languages use the same mechanism. A draft, stale profile, changed resource, unrelated review, same author/reviewer, non-clean coverage or absent next task cannot cause an automatic model request. Quiet waiting uses no model requests and makes no unchanged status writes. Genuine unrelated language or native blockers remain held.

Tests exercise actual local files, hashes, publication and supervisor continuation. A transport stub replaces a paid model call, and small resource bytes replace Unity serialization. They establish scheduling/provenance, not translation quality, Unity behavior or native acceptance.

No new translation, source/glossary edit, runtime, game, installer, server or publication permission is introduced. Per-request ready receipts are independently published, not a multi-request transaction.
