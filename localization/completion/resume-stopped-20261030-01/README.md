# Repair and resume the three stopped target streams

The owner explicitly requested the stopped locales repaired. At selection time
Chinese phase82, Spanish phase92 and Portuguese phase63 were terminal/blocked;
the other three language streams and the technical stream were active.

The first diverging boundary was the old observer's source-wake predicate: it
required a changed global source manifest, complete admission and a whole-game
denominator before either retained lane could perform further work. It did not
consume the subsequent owner acceptance of the working Russian localization.
Spanish also had no applicable source wake. Status wording alone could not resume
any of these workers.

`continuation-config.json` binds the direct repair authorization, accepted Russian
artifact/source version, exact previous stopped result, finite affected IDs,
input hashes and actual work brief for each existing lane. `ownerResume` validates
those bindings before issuing a model request, archives the old checkpoint and
continues the same lane with its next numbered phase. It does not flip old source
flags, accept target wording/fonts/native output or create additional streams.
An empty/foreign/stale scope, changed input or changed stopped result rejects;
the same assignment cannot be replayed against a later blocked result.

The shared launcher uses `--continuation-config`. Its old default source-wake
launch is rejected after owner acceptance of Russian, before pausing an observer.
This prevents the obsolete recipe from reintroducing the same wait. Current
runtime is selected by `outputs/locale-assets-20261026/launch-current.json`;
do not rerun the historical command or duplicate an accepted handoff.

## Handoff and verification

The verified old observer is paused while its state is reconciled. A frozen
successor declares readiness before that exact old observer exits; surviving
model children retain their identities and are adopted. Only then is the handoff
committed and current-run pointer advanced. Before commit, a failed attempt
preserves the old observer and children. Unknown postcommit outcomes must be
reconciled through their exact run/process identity, never resubmitted blindly.

`receipt.json` records the real run, runtime/process checks and the preserved
children. Actual fresh gpt-6.1-sol/high/OpenAI/no-parent metadata is required for
all seven streams. Test fixtures replace model/CLI behavior; they establish
continuation/guard boundaries, not linguistic quality or native game operation.
The final replay/default-launch guards apply to future launches. The active
observer retains its original verified immutable runner snapshot.
