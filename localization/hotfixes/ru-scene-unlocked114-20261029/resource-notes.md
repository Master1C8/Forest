# Scene-unlock notification resource adapter

The finite static resource adapter passes for 114 existing TMP `m_text` fields
in seven complete native notification pages. The saved resource changes exactly
114 of 18,905 native objects; all 18,791 unselected objects retain their exact raw
bytes. Every selected tree matches its pinned before-tree and differs only in
`m_text`. This preserves existing artwork, geometry, masks, font bindings, Blue,
swim, bell and journal content, and scene-unlock state.

The 19 groups contain six original text layers each: 12 whole-string headings
(72 fields) and seven complete gallery hints (42 fields). The headings preserve
both size-22 and size-36 spans. BunnyHandjob's `Title` uses size 22 despite its
unsuffixed object name. These are whole headings; no split-title joins are used.
The supplied target wording and editorial packet remain unchanged.

`tools/russian_scene_notifications.py` exposes `load_inputs()`,
`snapshot(out)` returning `out/scene-notifications`, and
`apply(source, output, *, locale='ru', fail_after_resource=False)`. Its CLI accepts
`--locale ru --source <Data> --output <fresh-folder>`. Successful output contains
only `sharedassets2.assets` and `Result.json`, whose `resource` and
`targetSha256` identify the delivered bytes. Public loading, snapshotting and
application require the matching clean independent review, full 114-ID coverage,
matching review-context hash, target hash and font requirements.

The implementation reuses `_project_native_tmp` from
`tools/russian_bell_notifications.py`. Both wrappers use the same guarded TMP
projection, actual saved-file readback, exact selected-ID/raw-byte comparison,
complete target-tree comparison, group validation and whole-container reversal.
The bell adapter's public API, 72-field contract, output bytes and receipt
metadata remain unchanged; its 18 split-title joins retain their original check.
